# 中文自然排序 (CN Natural Sort)

Obsidian 社区插件。让**文件浏览器（左侧文件列表）**按中文数字自然排序，例如：

- `第一章读书笔记` → `第四十六章读书笔记` 顺序正确（不再按 Unicode 码点乱排）
- 兼容阿拉伯数字 `第12章`、西式 `Lecture 57`、行首编号 `11. 第十一章` / `01_高等数学`
- **不改文件名、不改文件内容**，只重排显示顺序

## 排序规则
对每个文件/文件夹名，按以下优先级提取「序号」：

1. 中文：`第X章 / 第X节 / 第X卷 / 第X篇 / 第X回 / 第X部`（一~九十九、一百、一千、一万均可）
2. 阿拉伯：`第12章 / 第3节`
3. 西式：`Lecture 57` / `Lesson 3`
4. 行首编号：`11. 第十一章` / `01_高等数学` / `00-历史学MOC`
5. 兜底：名字里任意数字串做自然排序（如 `a2` < `a10`）

带序号的条目排在前面并按数字大小排；无序号的按自然字符串排。

## 安装 / 启用
1. 关闭 Obsidian 的「限制模式（Safe/Restricted mode）」：设置 → 选项 → 关于 → 关闭「限制模式」。
2. 本插件已放在仓库的 `.obsidian/plugins/cn-natsort/` 目录（含 `main.js` / `manifest.json` / `styles.css`）。
3. 打开 Obsidian → 设置 → 社区插件 → 在列表里找到「中文自然排序 (CN Natural Sort)」→ 启用。
4. 启用后文件浏览器会自动重排；也可点左侧栏的排序图标或命令面板「按中文自然排序重新整理文件浏览器」手动触发。

> 若与其他「自定义排序」类插件（如 Custom File Explorer sorting）同时启用，排序结果可能互相打架，建议只保留一个。

## 说明
- 本插件通过监听文件浏览器 DOM 变化后重排实现，不依赖 Obsidian 内部排序 API，跨版本更稳。
- 卸载：在设置里关闭并禁用即可，文件浏览器恢复 Obsidian 默认排序。
